# هم‌نشان برای ویندوز

خروجی مستقل ویندوز ۱۰ و ۱۱ نسخهٔ ۶۴ بیتی، `Hamneshan-1.0.0-Windows-x64.exe` است. فایل را در پوشهٔ دلخواه بگذارید و دوبار کلیک کنید. روی کامپیوتر استفاده‌کننده، نصب Node.js یا اتصال اینترنت لازم نیست. فونت‌های B Titr و B Koodak و کتابخانهٔ خواندن اکسل داخل برنامه قرار دارند.

## محل اطلاعات و خروجی‌ها

اطلاعات در حساب ویندوز فعلی و پوشهٔ `%APPDATA%\Hamneshan`، با IndexedDB نگهداری می‌شوند. این پوشه از اطلاعات برنامهٔ هم‌درس جداست. جابه‌جایی یا جایگزینی EXE اطلاعات قبلی را پاک نمی‌کند. اجرای دوبارهٔ فایل، همان پنجرهٔ موجود را جلو می‌آورد.

برای انتقال اطلاعات به دستگاه دیگر، از داخل برنامه نسخهٔ پشتیبان JSON بگیرید و در دستگاه جدید بازیابی کنید. خروجی کارت تولد، CSV و پشتیبان با پنجرهٔ انتخاب محل ذخیره دریافت می‌شوند. حذف پوشهٔ اطلاعات برنامه، داده‌های آن حساب را حذف می‌کند؛ از پشتیبان برای انتقال استفاده کنید.

اگر نسخهٔ شخصی‌سازی‌شده همراه با فایل `school-data.hamneshan.json` تحویل داده شود، این فایل باید کنار EXE باقی بماند. برنامه در نخستین اجرای بدون اطلاعات، دادهٔ اولیه را از همین فایل ثابت می‌خواند. پس از ورود اطلاعات، تغییرات در پوشهٔ حساب ویندوز ذخیره می‌شوند. فایل اطلاعات اولیه یا پشتیبان مدرسه را در گیت‌هاب قرار ندهید؛ گردش‌کار ساخت، هیچ اطلاعات واقعی مدرسه‌ای را دریافت یا بسته‌بندی نمی‌کند.

## دریافت EXE از گیت‌هاب با مرورگر

در مخزنی که سورس در زیرپوشهٔ `hamneshan` قرار گرفته است:

1. تب **Actions** را باز کنید و گردش‌کار **Build Hamneshan Windows x64** را انتخاب کنید.
2. **Run workflow** را بزنید و شاخهٔ شامل آخرین سورس را انتخاب کنید. با تغییر فایل‌های `hamneshan`، ساخت به‌صورت خودکار هم اجرا می‌شود.
3. پس از سبز شدن اجرا، بخش **Artifacts** را باز کنید و `Hamneshan-1.0.0-Windows-x64` را بگیرید.
4. ZIP را باز کنید. فایل EXE و `SHA256SUMS.txt` داخل آن هستند. برای استفاده، EXE کافی است.

دریافت Artifact به ورود به گیت‌هاب و دسترسی به مخزن نیاز دارد. Artifactها ۳۰ روز نگهداری می‌شوند. این گردش‌کار انتشار عمومی Release انجام نمی‌دهد. فایل اجرایی امضای تجاری دیجیتال ندارد.

## ساخت محلی برای توسعه‌دهنده

پیش‌نیاز ساخت، Node.js 24 یا جدیدتر و npm است. در ریشهٔ پروژهٔ هم‌نشان یا زیرپوشهٔ `hamneshan` اجرا کنید:

```powershell
npm ci
npx --no-install install-electron
npm test
npm run desktop:win
npm run test:desktop
```

خروجی در `release/` ساخته می‌شود. `npm run desktop:dev` برنامه را برای توسعه باز می‌کند. `desktop:prepare` وجود همهٔ فایل‌های رابط، فونت‌ها و مرز جداسازی فایل اطلاعات شخصی را بررسی می‌کند. چون رابط به‌صورت HTML و JavaScript آماده است، به سرور Node در نسخهٔ ویندوز احتیاجی نیست.

آزمون دسکتاپ در موتور واقعی Electron، بارگذاری ماژول‌ها و فونت‌ها، دسترسی محدود preload، کنترل مسیر فایل‌ها، خواندن فایل اولیهٔ ثابت و ماندگاری IndexedDB پس از بستن و اجرای دوباره را با دادهٔ موقت بررسی می‌کند. این آزمون به اطلاعات اصلی مدرسه دست نمی‌زند. اجرای آزمون در لینوکس، جای بررسی فایل نهایی روی ویندوز واقعی را نمی‌گیرد.

## ساختار نسخهٔ دسکتاپ

`desktop/main.mjs` پنجرهٔ برنامه و مبدأ ثابت `hamneshan://app/` را ایجاد می‌کند. فایل‌های رابط فقط از `dist/` خوانده می‌شوند. Renderer به Node.js دسترسی ندارد، در sandbox اجرا می‌شود، و `contextIsolation` فعال است. API محدود preload فقط دادهٔ اولیه را از نام فایل ثابت کنار EXE می‌خواند. ناوبری بیرونی، پنجرهٔ جدید و درخواست شبکهٔ خارجی در نسخهٔ مستقل بسته هستند.

تولدهای روز در داخل برنامه نمایش داده می‌شوند؛ برای مشاهده باید برنامه باز باشد. این نسخه در پس‌زمینهٔ ویندوز پیام کانال ارسال نمی‌کند. کارت را بازبینی و دانلود کنید و خودتان در کانال قرار دهید.
