# هم‌نشان؛ دفتر هوشمند مدرسه

نرم‌افزار فارسی ویندوز برای جست‌وجوی سریع دانش‌آموزان، دبیران و خانواده‌ها، شناسایی تماس با چهار رقم آخر موبایل یا تلفن ثابت، جست‌وجوی شغل والدین و ساخت کارت تبریک تولد.

- رابط راست‌چین با فونت‌های محلی **B Titr** و **B Koodak** و لوگوی مدرسه.
- همهٔ تطبیق‌های شماره با نسبت ثبت‌شده نمایش داده می‌شوند؛ شمارهٔ مشترک یا تلفن منزل هویت قطعی تماس‌گیرنده را مشخص نمی‌کند.
- نمایش مشخصات، تماس‌ها، شغل‌ها و تمام ستون‌های اصلی در همان صفحه؛ امکان ویرایش و افزودن عکس.
- تولدهای امروز، هفته و ۳۰ روز آینده با تقویم شمسی و ساعت تهران؛ کارت PNG به اندازهٔ ۱۰۸۰×۱۰۸۰، عکس، لوگو و متن قابل ویرایش؛ کپی پیام کانال.
- شناسایی قالب اصلی دو فایل مدرسه، انتخاب کاربرگ، نگاشت ستون‌های فایل‌های دیگر، ورود XLSX/XLS/CSV و گزارش خطا و تکرار.
- اطلاعات و عکس‌ها در دستگاه کاربر ذخیره می‌شوند. خروجی و بازیابی پشتیبان JSON در دسترس است.

## نسخهٔ ویندوز

فایل `Hamneshan-1.0.0-Windows-x64.exe` روی ویندوز ۱۰ و ۱۱ نسخهٔ ۶۴ بیتی اجرا می‌شود. نصب Node.js یا اینترنت برای استفاده لازم نیست. برای ورود اولیهٔ اطلاعات واقعی، فایل خصوصی `school-data.hamneshan.json` را کنار EXE بگذارید و برنامه را باز کنید؛ در اولین اجرای خالی به‌صورت خودکار وارد می‌شود. همچنین از «تنظیمات و پشتیبان ← بازیابی پشتیبان» می‌توان داده‌ها را وارد کرد.

اطلاعات در `%APPDATA%\Hamneshan` حساب ویندوز شما نگهداری می‌شود. جابه‌جایی یا تعویض EXE اطلاعات را پاک نمی‌کند. نسخهٔ هم‌درس پوشه و اطلاعات جداگانه دارد. قبل از جابه‌جایی دستگاه یا تغییرات گسترده، پشتیبان بگیرید.

اگر فایل آمادهٔ مدرسه کنار EXE نباشد، برنامه با نمونه‌های مشخص‌شده شروع می‌شود. با ورود اولین فایل واقعی، نمونه‌ها کنار گذاشته می‌شوند. داده‌های نمونه هیچ ارتباطی با افراد مدرسه ندارند.

## ساخت از گیت‌هاب

در مخزن، بخش **Actions → Build Hamneshan Windows x64 → Run workflow** را باز کنید و شاخهٔ دارای این برنامه را انتخاب کنید. پس از موفقیت، فایل **Hamneshan-1.0.0-Windows-x64** از بخش **Artifacts** قابل دانلود است. راهنمای کامل در [docs/windows-build.md](docs/windows-build.md) قرار دارد. سورس در پوشهٔ `hamneshan` است و ساخت خودکار با تغییرات آن اجرا می‌شود.

در کامپیوتر توسعه با Node.js 24:

```sh
cd hamneshan
npm ci
npx install-electron
npm test
npm run desktop:dev
npm run desktop:win
npm run test:desktop
```

در لینوکس ابری نصب موتور با `electron_config_cache=/workspace/.cache/electron node --use-env-proxy node_modules/electron/install.js` و ساخت با `XDG_CACHE_HOME=/workspace/.cache ELECTRON_BUILDER_CACHE=/workspace/.cache/electron-builder NODE_USE_ENV_PROXY=1 npm run desktop:win` انجام می‌شود. مسیرهای کش مخصوص این محیط‌اند.

## داده‌های مدرسه و محدودیت‌ها

اطلاعات شخصی، فایل‌های اکسل و عکس‌های واقعی در سورس یا خروجی عمومی گیت‌هاب قرار نمی‌گیرند؛ فایل اولیهٔ خصوصی جداگانه تحویل داده می‌شود. لوگوی وکتوری و فونت‌ها برای کارکرد آفلاین بسته‌بندی شده‌اند؛ منبع و اطلاعیهٔ فونت‌ها در `dist/assets/fonts/README.md` است.

قالب فعلی دانش‌آموزان «کلاس سال قبل» را دارد؛ این مقدار در مشخصات اصلی محفوظ می‌ماند و کلاس فعلی از آن حدس زده نمی‌شود. دو پاسخ دبیران کد ملی یکسان دارند و با علامت ثبت تکراری حفظ می‌شوند. تاریخ‌های نامعتبر تا اصلاح در تقویم تولد نمایش داده نمی‌شوند. در سال غیرکبیسه، تولد ۳۰ اسفند در ۲۹ اسفند نشان داده می‌شود.

عکس‌ها در فایل اکسل جاسازی نشده‌اند. لینک‌های عکس دبیران در اطلاعات اصلی محفوظ‌اند؛ برای استفادهٔ آفلاین می‌توان عکس را از «ویرایش و عکس» یا کارت تولد افزود. برنامه هیچ فایل یا لینکی را خودکار از اینترنت دریافت نمی‌کند. تولدها هنگام باز بودن برنامه روزانه تازه می‌شوند؛ ارسال خودکار پیام یا اعلان در زمان بسته بودن برنامه پیاده نشده است.

EXE امضای تجاری ندارد. آزمون اجرای واقعی Electron و داده‌ماندگاری در لینوکس، جای آزمون دستی فایل نهایی روی ویندوز واقعی را نمی‌گیرد.
